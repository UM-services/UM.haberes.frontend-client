# @haberes/shared-api

Capa de API compartida: AuthService para gestión de sesión y cambio de clave (`changePassword` sobre `PUT /api/haberes/core/usuario/cambiarclave`, con el payload tipado `ChangePasswordRequest`), authGuard y unauthGuard para protección de rutas, `moduloGuard` (restricción por facultad según `data.requireFacultadId`: `true` exige facultad asignada, `false` la exige nula) y administradorGuard, y PersonaSearchService como acceso único al buscador de personas de haberes-core (`/api/haberes/core/persona`: `POST /search` multi-término, `GET /{legajoId}` y `GET /documento/{documento}`), consumido por el componente estándar `ui-persona-search` de `@haberes/ui-layout`. `AuthService` expone además `facultadId` como señal de sesión, para que las pantallas filtren por la facultad asignada sin suscripciones manuales a `currentUser$`.
